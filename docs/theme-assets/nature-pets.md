# Nature Pets

Independent native Nature-family package with a nine-section home page, pet collection cards, a split FAQ, product and category templates. The observed family header, footer, cart, slideshow and product/review presentation are reused from Nature Kids. This is not an alias to another theme.

Reference: https://nature-pets.myeasyorders.com/ reviewed on2026-10-18. Current reference measurements and the152-theme coverage audit are preserved outside the repositories. Full visual and functional parity still requires browser validation.

Bundled campaign photography reuses the three original Sellchaze-generated pet images documented in [Blast Pets assets](blast-pets-assets.md). Three portrait derivatives were generated with the built-in image generation tool for mobile slides and demo cards. Their exact prompts, input paths and provenance are recorded in [the prompt set](nature-pets-image-prompts.json). No reference product photos, brand, store contacts or marketing copy are shipped. Merchant categories, photos, copy, collections and footer identity remain editable. Demo pet data is isolated from resolved merchant stores.

The gallery thumbnail is a direct browser capture of this native package at1200×1500, using the isolated Sellchaze pet demo catalog. It contains only the existing generated assets and rendered UI; no competitor thumbnail is copied.
